# Round 1 Entry Draft

**Track:** Cybersecurity AI Agents

Companies are giving AI agents access to email, files, and business tools. A malicious instruction hidden in an ordinary-looking invoice can mislead an agent into exposing private information or recording an unauthorized payment. Aegis Loop is a security layer for a fake finance assistant: it tests the agent with untrusted content, blocks and repairs the weaknesses it finds, tries the attack again, and saves evidence that the fix works while normal tasks still pass. Every test uses local fake data; no real email, account, or payment system is connected.
